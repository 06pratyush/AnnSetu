# BrandMark

BrandMark is the AnnSetu wordmark: the name in Anek Devanagari 700 with its Devanagari twin, beside a bridge arc whose farm half is `khet` and buyer half `neel`, crowned by a `haldi` grain.

There is no official logo yet; this mark is a stand-in drawn for the project. Use `compact` in app headers.

## Props

```ts
export interface BrandMarkProps { compact?: boolean; className?: string }
```
