# Card

Card sets one object apart: `surface` fill, hairline `border`, `radius-md`, no shadow at rest. Use it by role (a form, a chart, a summary), not around every block. CardHeader, CardTitle (h3 style), CardDescription and CardContent keep the padding consistent: 16px on phones, 24px from sm.

## Props

```ts
export interface CardProps extends React.HTMLAttributes<HTMLDivElement> {}
```
