# CategoryIcon

CategoryIcon draws the lucide icon for a produce category: Carrot (vegetables), Apple (fruits), Wheat (grains), Bean (pulses), Flame (spices), Milk (dairy), Droplet (oilseeds), Sprout (others). Use it on chips, on demand cards, and as the photo stand-in.

## Props

```ts
export interface CategoryIconProps { category: CategorySlug; className?: string }
```
